PDF Reader Settings

The AI Popup Infopedia supports reading and translating PDFs using a built-in viewer.

When enabled, PDFs opened in a tab are shown in the extension's custom viewer with highlights and popups; password-protected PDFs ask for their password right in the custom viewer. Turn this off to always use Chrome's built-in PDF viewer. If a document still fails to load in the custom viewer, an "Open in Chrome's built-in viewer" button is offered on its error screen.

Local PDF Access is Disabled

To use the AI Popup on PDFs saved to your computer (file:// URLs), you must allow file access in Chrome.

Export or import all your configured models and the global prompt. This does not include your word history or lists. Warning: the export file contains your API keys (model, web-search, and speech-to-text) in plain text — store it securely and do not share it.

Erase everything — models and API keys, custom prompts, vocabulary history and word lists, flashcard progress, and all other settings (Anki, TTS/STT, PDF, backup schedule) — and return the extension to a fresh-install state. This cannot be undone. Consider creating a backup first.

Interactive Troubleshooting Guide

1. Keyboard Shortcut: The default hotkey is Ctrl+Shift+Y (or Cmd+Shift+Y on Mac). You can customize this shortcut at chrome://extensions/shortcuts.

2. Chrome Restricted Pages: By design, Chrome prohibits all browser extensions from running on internal pages (chrome://, chrome-extension://, New Tab page) and the official Chrome Web Store website. Test on regular websites like Wikipedia or news articles.

3. Page Reload: If you just installed or updated the extension, existing open browser tabs need to be refreshed once for the helper script to activate.

401 Unauthorized means the AI provider rejected your API key. Here is how to get free/supported keys:

  • Google Gemini (Free tier): Get a key at Google AI Studio. Endpoint: https://generativelanguage.googleapis.com/v1beta/openai/chat/completions, Model: gemini-2.5-flash.
  • Groq (Ultra-fast, Free tier): Get a key at Groq Console. Endpoint: https://api.groq.com/openai/v1/chat/completions, Model: llama-3.3-70b-versatile.
  • OpenRouter: Supports dozens of models at openrouter.ai. Endpoint: https://openrouter.ai/api/v1/chat/completions.

Use the " Test Connection" button above to verify your key and endpoint in real time.

Infopedia supports 100% private, local LLMs running on your own computer:

For Ollama:

  • Endpoint URL: http://localhost:11434/v1/chat/completions
  • Model Name: Any installed model (e.g. llama3.2, mistral, qwen2.5).
  • API Key: Leave blank.
  • Enable CORS: In Windows/Mac/Linux, set the environment variable OLLAMA_ORIGINS="*" before starting Ollama so Chrome can connect to localhost.

Web Search Grounding allows models to fetch up-to-date facts, current events, and live web citations:

  • Get a free Tavily API key at tavily.com.
  • Save your key in the Search API Settings section on the Model Settings tab.
  • Check "Enable Web Search" when adding or editing your AI model.

Infopedia includes a built-in custom PDF reader with multi-color highlights, bookmarks, search grounding, and Anki card creation:

  • Digital PDFs: Select any text inside the PDF to highlight, define, or speak aloud.
  • Scanned PDFs / Images: Scanned image PDFs without an embedded text layer must be OCR-processed to select text.
